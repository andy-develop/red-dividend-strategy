    术语表（黑话翻译）
    满仓 100%把本金全部买成 ETF，不借钱。
    加仓 125% / 150%借 25% / 50% 的钱多买（需要融资融券账户），买完最多持有 60 天。
    周线 KDJ 的 J 值每周看一次的市场情绪指标。J<1 说明恐慌到极点（超卖），J>95 说明贪婪到极点（超买）。
    布林轨把 20 天均价上下各拉一条 2 倍波动的通道。跌破下轨=跌过头，涨穿上轨=涨过头。
    2-of-4 共振4 个"跌过头"信号里至少 2 个同时出现才抄底，避免单看一个指标被骗。
    动能消失 / 顶背离价格还在创新高，但上涨的劲头已经减弱（比如 RSI 没跟上）——见好就收，把加仓部分卖掉。
    60 自然日纪律每次加仓后最迟 60 天必须卖掉，防止借钱时间太长、风险失控。
    清仓离场 / 空仓涨太多（3 个过热信号同时满足）时全部卖出落袋，等回调后再买回。
    融资融券券商的借钱炒股业务：门槛 50 万资产 + 半年交易经验。没有两融账户就只做 100% 底仓，忽略加仓信号。

    策略说明与数据口径（给懂行的人）
    • 超卖买点＝2-of-4 × 双重门槛（v7.12）：4 个恐慌信号（周线 J<1 / 跌破布林下轨 / 近 63 日跌幅≥14% / 周线 RSI<35）任意 2 个，且 价格 <250 日线（年线下方才抄底，年线上方超卖=高位回调不执行）且 估值剪刀差（股息率代理−10Y国债）3 年历史分位 ≥50%（<50% 不执行；50-80% 半力=禁加仓至150%）；抄底胜率按含滑点成交价 FIFO 配对。
    • A 态清仓＝超买三维极值：J>95 且 触及/突破上轨 且 up63≥20% → 离场 0%；离场后出现超卖信号可提前回补，最迟 90 自然日强制回补。
    • 临时仓卖出＝动能消失确认（任一）：J 从>90跌破80 / RSI 从>70跌破65 / 10日顶背离（收盘创新高且日线 RSI 未新高）；每档 25% 独立 60 自然日到期强制卖出。
    • 执行口径（v7.12）：信号用价格指数 H30269 计算、收益用全收益 H20269；T+1 收盘成交（无开盘价近似）+ 单边滑点 5bp；杠杆年化 7% 按交易日计息；费用单边 max(万1, 5元)；年化 252 交易日、夏普无风险利率 0。
    • 情绪温度计算法：0.4×J(截断0-100) + 0.4×周线RSI + 0.2×动量分(100+dn63×3 截断0-100)，仅作直观参考，不参与任何买卖信号。
    • 过拟合体检：8 参数敏感性（除 X_UP 外均参数平原）+ walk-forward 三区间夏普 0.45/0.56/0.75，见仓库 backtest/sensitivity.json；PBO/Deflated Sharpe 未实现。
