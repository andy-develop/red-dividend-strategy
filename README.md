## 每日更新逻辑（update.py）

1. **抓行情**：中证指数官网 `index-perf` 接口，抓 H20269（全收益，回测标的）与 H30269（价格指数）最近 3800 个自然日收盘价（覆盖 2016-09-08 回测起点、MA200、周线KDJ收敛、63日动量与状态机重放余量；接口限流自动退避重试）。
2. **算指标**（与 10 年回测口径完全一致）：
   - 布林带：20 日均线 ± 2×标准差（ddof=0）
   - 周线 KDJ(9,3,3)：ISO 周重采样，K/D 初值 50，J=3K−2D，周末定值回填
   - 周线 RSI(14) Wilder（合理区间 35-70）与日线 RSI(14)（顶背离用）
   - 近 63 日动量：up63（自最低收盘涨幅）/ dn63（自最高收盘跌幅，超卖阈值 −20%）
3. **状态机重放**（v7.6 四态 A/B/C/D）：
   - 超卖买点＝2-of-4 共振：J<1 / 跌破布林下轨 / dn63≤−20% / 周线RSI<35 任意 2 个 → 加仓 125%（再触发至 150%）
   - A 态清仓＝超买三维极值：J>95 且 触及/突破上轨 且 up63≥20% → 离场 0%
   - 临时仓（125/150%）卖出＝**动能消失确认**，任一触发即了结回 100%：J 从>90跌破80 / RSI 从>70跌破65 / 10日顶背离（收盘创新高且日线RSI未新高）
   - 到期兜底：每档 25% 独立 60 自然日；离场后 60 自然日强制回补
4. **触发预告**：计算距「超卖 2-of-4 / 超买三维极值 / 动能消失」还需的跌幅/涨幅缺口（布林轨缺口、63日动量缺口、周线 J/RSI 状态），页面展示"今天如果再跌 X% 将触发…"。
5. **生成自包含 index.html**：内嵌今日快照 + 静态回测数据，覆盖写入。
